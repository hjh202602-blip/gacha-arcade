# 몽글몽글 인형뽑기

브라우저에서 즐기는 뽑기방 웹사이트예요. 매장에서 기계를 골라 인형을 뽑고, 뽑은 인형은 진열장에 모여요.

**플레이:** https://hjh202602-blip.github.io/gacha-arcade/

## 기계 (21대)
| 기계 | 방식 |
|---|---|
| 몽글 동물원 · 달콤 디저트 · 우주 몬스터 · 전설의 보물섬 | 인형뽑기. 정중앙이면 거의 잡히고(어려운 기계일수록 정중앙 범위가 좁음), 가까우면 일정 확률로 걸리며(들고 가다 떨어질 확률 10% 미만), 옆을 잡으면 밀려남 |
| 캡슐 토이 | 레버를 돌려 캡슐 뽑기 (운) |
| 골든 레버 캡슐 | 빙글빙글 도는 레버를 금색 칸에서 멈추면 S·A 확률 상승 |
| 펀치 챔피언 | 게이지 꼭대기에서 펀치 (점수) |
| 삼연타 펀치 | 세 번 쳐서 평균 점수, 칠 때마다 게이지가 빨라짐 |
| 10초 챌린지 | 3초 뒤 숫자가 사라지는 스톱워치 |
| 럭키 타이머 | 목표 시간이 매번 바뀌고(5~15초), 1.5초 만에 숫자가 사라짐 |
| 열쇠고리 걸기 | 지나가는 고리에 갈고리 쏘기 |
| 지그재그 키링 | 벨트 속도가 출렁이고 거꾸로도 감 |
| 키 마스터 | 가로·세로로 멈춰 열쇠구멍에 넣기 |
| 미끄럼 키 마스터 | 열쇠구멍이 좌우로 움직임 |
| 싹둑 가위 | 누르고 있다가 떼서 흔들리는 실 자르기 |
| 왕복 가위 | 가위가 혼자 왕복하고 점점 빨라짐, 탭으로 자르기 |
| 스태커 | 블록 쌓아 꼭대기까지 |
| 코인 푸셔 | 코인을 떨어뜨려 코인과 인형을 밀어내기 (높은 등급이 잘 나옴: S 6% · A 14% · B 24%) |
| 번개 반응 | 초록불이 켜지는 순간 탭 (반응속도), 가짜 노란 번쩍임 주의 |
| 쏙쏙 터치 | 구멍에서 나오는 인형 터치 (반응속도), 폭탄 -2 · 빈 구멍 -1 |
| 따라해 멜로디 | 빛나는 순서 기억해서 따라 누르기 (암기) |

## 인형
- 직접 그린 오리지널 인형 110종이 기본이에요(코드로 그림, 외부 이미지 없음).
- 기본 인형마다 **색을 바꾼 인형**과 **옷·모자를 입힌 인형**(털모자·목도리·멜빵·망토·꽃핀·나비넥타이·선글라스)이 자동으로 조합돼요. 특별 뽑기 전용 **오로라 인형**까지 모두 440종이에요.
- 입수 난이도에 따라 S(전설) · A · B · C · D 등급이 매겨져요.
- 같은 인형을 여러 번 뽑을 수 있고, 진열장에서 팔아 코인으로 바꿀 수 있어요 (S 50 · A 15 · B 6 · C 3 · D 1코인).
- 진열장의 **🧺 골라서 일괄 판매**로 여러 인형을 한 번에 팔 수 있어요. 등급별·전체 빠른 선택과 "종류마다 1개 남기기" 옵션이 있어요.
- 처음엔 기계 3대만 열려 있고, 나머지는 코인으로 해금해요 (20~150코인).
- 1회 가격은 인형을 얻기 쉬운 기계일수록 비싸요 (1~3코인).

## 매장 이벤트
- **오늘의 인형 TOP 3:** 매일 C~S 등급 인형 3개가 정해지고(높은 등급일수록 드물게), 그날 그 인형을 팔면 판매가가 x1.5~2.5배가 돼요. 배율 확률은 x1.5 40% · x1.8 30% · x2.0 18% · x2.2 8% · x2.5 4%예요.
- **오늘의 무료 코인:** 하루 한 번 5~15코인을 랜덤으로 받아요.
- **특별 뽑기:** 매시 정각과 30분에 시작해 10분 동안, 해금된 기계 2대에서 평소 인형 대신 오로라 인형이 나와요.

## 당첨 연출
- 등급이 높을수록 연출이 커져요. D·C·B는 꽃가루와 반짝이가 바로 터져요.
- A·S는 검은 실루엣이 떨리며 빛을 모았다가 공개돼요. 공개 순간 화면이 번쩍이고 흔들리며 폭죽이 터져요.
- 효과음은 직접 합성해요. 상단의 🔊 버튼으로 끌 수 있어요.

## 보안
- 코인과 저장 데이터는 코드 안에 감춰져 있어서 브라우저 콘솔에서 바로 바꿀 수 없어요.
- 저장 데이터에는 서명이 붙어 있어서, 직접 고치면 처음 상태로 초기화돼요.
- 등급 확률, 기계 힘, 인형 데이터, `Math.random`은 바꿀 수 없게 잠겨 있어요.
- 다만 서버 없이 브라우저에서만 도는 게임이라 완벽하게 막을 수는 없어요.

## 개발자 모드
로고를 빠르게 5번 누르거나 `Ctrl+Shift+D`를 누른 뒤 암호를 넣으면 열려요. 코인 지급, 해금, 특별 뽑기 시작/끝, TOP3 다시 정하기, 당첨 연출 미리보기, 저장 초기화를 할 수 있어요. 코드에는 암호의 해시만 들어 있어요.
